# 控制台布局参考

参考 Cloudflare 的 [2026 DNS 面板更新](https://developers.cloudflare.com/changelog/post/2026-05-20-new-dns-records-ux/) 与 [DNS 记录管理说明](https://developers.cloudflare.com/dns/manage-dns-records/how-to/create-dns-records/)。采用灵活的记录表格、长内容显示和手机端卡片；解释性文字通过按需帮助呈现。

| Before | After | Why |
| --- | --- | --- |
| 区域侧栏与全局侧栏并排 | 页头区域选择器与通栏表格 | 给名称和长记录值留出空间 |
| 编辑弹窗 | 新增在表格前、编辑在记录下方展开 | 操作时仍能看到记录所在上下文 |
| 分散的记录工具 | 搜索、筛选、列显示、导出集中排列 | 缩短常用操作的查找路径 |
| 手机缩小桌面表格 | 独立的记录卡片与分页 | 小屏直接阅读完整值和操作记录 |
| 装饰性的卡片和文案 | 中性灰边框、常规字号和区域信息 | 让 DNS 记录成为页面主体 |

Ant Design Vue 采用默认浅色和深色主题算法。右上角可选择跟随系统、浅色或深色，选择保存在当前浏览器并跨页面、刷新和登录状态保留。页面、表格、表单、抽屉、确认弹窗及消息反馈使用同一套主题；初始 HTML 提前应用主题，避免深色偏好下先闪现浅色页面。

解释性文案统一放入小问号：支持鼠标悬停、键盘聚焦、Escape 关闭及触屏点击。错误、实际运行状态、变更预览及删除确认继续直接展示。区域信息仅展示区域名称、维护方式、主从节点及 SOA；DNS、DHCP、登录和审计页面移除常驻介绍和说明脚注。

可用功能：按名称或内容搜索、类型过滤、系统记录和可编辑记录过滤、内容/维护方式/TTL 列开关、当前筛选记录的 zone 文本片段导出、提交前变更预览。导出的文本片段包含当前筛选记录，不保证包含完整区域所需的 SOA/NS。

权限、TSIG、记录版本检查及审计均由既有后端执行，界面改版不修改生产 BIND 策略。

## 整体工作空间与 DHCP

侧栏按概览、DNS、DHCP 和审计分组，页面使用统一面包屑、标题、工具条和数据列表。导航搜索筛选实际页面，URL hash 保留当前页，刷新或浏览器后退可恢复。

概览使用资源列表呈现 DNS 区域与 DHCP 子网，并汇总真实记录、租约和节点状态。DHCP 包括子网与地址池、保留地址、租约和 HA 四个页面。手机端为子网、保留地址及租约提供独立卡片；确认变更时显示内容预览和双节点校验结果。

登录、审计筛选及变更详情沿用相同字体、留白和边框。保留 Ant Design Vue 的原生按钮、表单和反馈样式，橙色仅用于 InfraPilot 自有标识。
